Strategy AI Toolkit

Three working models of how AI can support a strategy consultancy: winning the work, researching it, and tracking whether the strategy delivers. Each tool shows its working, so a consultant can check every result before it is used.

Built by Deeksha Gulati using public documents and illustrative sample data only. Source code: see the GitHub repository linked in the README.

Tender Fit Checker

Before a bid goes in: AI lists the tender's mandatory requirements and weighted award criteria, then rates how well the draft response addresses each one, quoting the draft as evidence. Gaps are ranked by the marks at risk.

What the code checks: every evidence quote must appear word for word in the draft, or the rating is not trusted; every weight must appear in the tender; weights must add up to 100%. What the bid manager still checks: every rating, and whether each fix is true of the firm.

Both boxes hold a fictional example: a request for tender and a deliberately incomplete draft. Paste your own to try it.

Consultation Analyser

Groups free-text stakeholder responses into themes, counts how often each comes up, and pulls an example quote. The page then checks every quote word for word against the original response, so nothing invented gets through.

What the consultant still checks: every theme, the responses filed under it, and the less common points flagged at the end, which AI tends to underweight.

Outcome Tracker

After a strategy launches: AI separates the plan's actions into outputs (work done) and outcomes (change for people), proposes indicators to measure the outcome, then drafts the progress update for the chosen audience.

Example used: HIQA's public Corporate Plan 2025–2027, which commits to building an outcome framework in its first year. Actions are lightly abridged. Statuses in the progress update are illustrative, not HIQA's real progress.
